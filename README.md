# Web Performance

Repositório de estudos sobre **Web Performance**, com foco em entender como medir, analisar e melhorar o desempenho de aplicações web.

## Objetivo

Construir conhecimento prático sobre performance web, desde os principais conceitos e métricas até ferramentas de análise, diagnóstico, monitoramento e otimização.

## Conteúdos

### Core Web Vitals

* **LCP — Largest Contentful Paint**
* **INP — Interaction to Next Paint**
* **CLS — Cumulative Layout Shift**

Para cada métrica:

* O que ela mede
* Por que é importante
* Qual é um bom resultado
* Como interpretar os resultados
* Como coletar os dados
* Principais causas de problemas
* Como diagnosticar
* Como otimizar

### Métricas complementares

* **FCP — First Contentful Paint**
* **TTFB — Time to First Byte**
* **TBT — Total Blocking Time**
* Outras métricas relevantes de performance

## 📊 Dados de Performance

### Dados de laboratório

Medições realizadas em ambientes controlados para reproduzir e investigar problemas de performance.

Ferramentas:

* Lighthouse
* Chrome DevTools
* PageSpeed Insights
* WebPageTest

### Dados de campo

Medições coletadas a partir da experiência de usuários reais.

Conceitos estudados:

* RUM — Real User Monitoring
* CrUX — Chrome User Experience Report
* `web-vitals`
* Distribuição dos resultados
* Percentis
* Segmentação por dispositivo, conexão e outras condições

## Automação

Estudos sobre automação de testes e coleta de métricas de performance utilizando **Playwright**, incluindo:

* Execução automatizada de páginas
* Coleta de métricas
* Repetição de cenários
* Comparação de resultados
* Identificação de regressões de performance

## Front-end e Performance

Estudos relacionados ao impacto das decisões de desenvolvimento no desempenho:

* HTML
* CSS
* JavaScript
* React
* Carregamento de recursos
* Imagens
* Fontes
* JavaScript excessivo
* Renderização
* Network
* Cache
* Code splitting
* Lazy loading
* Bundle size
* SPA e navegação entre rotas

## WebView e Performance

Investigação de cenários específicos de aplicações **WebView**, considerando:

* Carregamento inicial
* Navegação
* Comunicação entre WebView e aplicação nativa
* Rede
* Dispositivo
* Renderização
* Impacto do ambiente do aplicativo na experiência do usuário
